---

## 📖 仓库简介 (Introduction)

本仓库采用**按学期分卷归档**的目录结构，将日常零散的课堂重点、教材定理与典型题型进行了系统化重构。资料主要由以下几类内容组成：
- 📝 **结构化课程笔记**：基于 Markdown 与 LaTeX 整理的核心概念、定理推导与知识框架（原生适配 Obsidian）。
- 🧮 **习题与解题方法总结**：工数、高代等核心课程的典型例题拆解、证明思路与题型归纳。
- 💻 **代码与课程报告**：程序设计类课程的源码实现，以及研讨课、通识课的文献阅读与论文写作框架。
- 🗂️ **复习提纲 (Cheatsheets)**：考前高频考点梳理、核心公式速查表与易错点汇总。
